# 📊 Power BI Data Analysis & Dashboard Project

## 📌 Project Overview

This project is a **Power BI data analysis and visualization project** created to transform raw data into meaningful insights through interactive dashboards and reports.

The project demonstrates how data can be cleaned, analyzed, modeled, and visualized using **Microsoft Power BI** to support data-driven decision-making.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze and understand the provided dataset.
- Clean and transform raw data.
- Create meaningful relationships between data tables.
- Develop interactive Power BI dashboards.
- Identify important trends and patterns.
- Present key performance indicators (KPIs).
- Make complex data easier to understand through visualizations.

## 🔄 Project Workflow

The project follows these major steps:

### 1. Data Collection
Raw data is imported into Power BI from the available data source.

### 2. Data Cleaning
The data is prepared using **Power Query**, including:

- Removing unnecessary columns
- Handling missing values
- Removing duplicate records
- Correcting data types
- Renaming columns
- Transforming data where required

### 3. Data Modeling

Relationships between tables are created to build an effective data model.

The model helps Power BI connect different datasets and perform accurate calculations.

### 4. DAX Calculations

DAX measures and calculated columns can be used to calculate important business metrics such as:

- Total
- Average
- Count
- Percentage
- Growth
- KPIs

### 5. Dashboard Development

Interactive visualizations are created to present the analysis clearly.

Examples include:

- 📊 Bar Charts
- 📈 Line Charts
- 🥧 Pie / Donut Charts
- 🔢 KPI Cards
- 📋 Tables
- 🔽 Slicers
- 📉 Trend Analysis
